# Logos

Logos of the projects that needy's drivers run on, as their projects publish
them. Retrieved 2026-11-12.

- `firecracker.svg`: Firecracker's icon.
  Source: https://github.com/firecracker-microvm/firecracker/blob/311ffed69cf1ce4e7e67f6e530612a57b047e502/docs/images/fc_logo_icon.svg
- `gvisor.png`: gVisor's site icon.
  Source: https://github.com/google/gvisor/blob/e2b96b8cf517159f07d93308851401379d19ecce/website/assets/favicons/pwa-192x192.png

The other marks (Docker, Linux, Apple, Windows, opencode, Ollama) come from
Iconify sets at build time (`@iconify-json/logos`, `@iconify-json/devicon`);
see `vite.config.ts`.
